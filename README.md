# Functional Time and Recoverability Window

A minimal computational framework for studying operational accessibility, recoverability collapse, and finite-time dynamical constraints.

This repository contains the complete simulations, figures, parameter sweeps, and manuscript associated with the exploratory ERC (Endogenous Reachability Collapse) framework.



---

## Core Idea

The framework explores whether systems may progressively lose operational recoverability before complete dynamical collapse occurs.

Rather than focusing exclusively on whether trajectories exist, the simulations investigate whether recoverable return pathways remain operationally accessible within finite recovery windows.

The results suggest that recoverability depends strongly on the interaction between:

- perturbation delivery timescale,
- intrinsic recovery dynamics,
- and finite operational recovery constraints.

## Main Components

The framework includes:

- deterministic recoverability boundaries,
- functional-time landscapes,
- ratio-organized accessibility transitions,
- sequential perturbation experiments,
- stochastic forcing robustness,
- and numerical sensitivity analyses.

---

## Minimal Operational Distinction

The simulations support a distinction between:

- structural admissibility of trajectories,
- and operational accessibility of recoverable trajectories under finite-time constraints.

---

## Reproducibility

All simulations were generated directly from the included notebook using openly available Python scientific libraries.

No proprietary datasets or private computational resources are required.

---

## Status

This project is exploratory and intentionally minimal.

It does not propose modifications to physical time or fundamental physical laws, but instead introduces a computational framework for studying recoverability-limited operational accessibility.
